# Git 练习仓库

这是用来练习 GitHub 基本流程的仓库。

## 要练的动作

1. 第一次提交（commit）
2. 新建分支改文件（branch + commit）
3. 合并回 main（merge，相当于合并一个 PR）
4. 推到 GitHub（push）

## 小抄

```
git status              看状态（最常用）
git add .               暂存改动
git commit -m "说明"     存档
git pull                拉取别人的更新
git push                推送到 GitHub
```
